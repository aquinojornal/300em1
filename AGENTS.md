# Instruções do projeto SLU

Ao usuário escrever "SLU", ler SLU-RETOMADA.md e retomar o projeto existente a partir do estado registrado. Antes de mudanças, consultar esse arquivo. A marca visual permanece SMLU.

WordPress está em wp; seguir wp/AGENTS.md e wp/STUDIO.md nesse diretório. Dados privados estão em .local-docs e .local-backups: nunca publicar, enviar ao Git ou servir essas pastas. Não executar seeds/reset/restaurações automaticamente.
